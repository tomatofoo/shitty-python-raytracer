# shitty-python-raytracer

![Render](/images/render.png)

This is a shitty raytracer made in Python. This is a raytracing experiment that
I made for fun.

## Usag
Use the flag `--size` or `-s` to change the size in px of the render 
(default 640x480), and use the flag `--path` or `-p` to change the path of the 
rendered file (default render.png).
